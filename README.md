# Loan Approval Prediction

A supervised machine learning model that predicts whether a loan application should be approved based on applicant attributes.

---

## Overview

- Performs exploratory data analysis and feature engineering on the loan dataset
- Handles missing values, encodes categorical variables, and scales features
- Trains and compares multiple classifiers: Logistic Regression, Decision Tree, Random Forest
- Evaluates with accuracy, confusion matrix, and ROC-AUC

## Tech Stack

Python, Scikit-learn, Pandas, NumPy, Matplotlib, Seaborn

## Run

```bash
pip install -r requirements.txt
jupyter notebook loan_approval.ipynb
```
